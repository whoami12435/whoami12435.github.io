Embedded Systems & IoT

การพัฒนาระบบ IoT และไมโครคอนโทรลเลอร์

การเชื่อมต่อซอฟต์แวร์ เซ็นเซอร์ และระบบคลาวด์เพื่อสร้างนวัตกรรมที่ใช้งานได้จริง

โครงงานเข็มขัดแจ้งเตือนการล้มอัจฉริยะ (ESP32 IoT)

การนำความรู้ด้านการเขียนโปรแกรมภาษา C มาพัฒนาบอร์ดไมโครคอนโทรลเลอร์ ESP32 เพื่ออ่านค่ามุมและความเร่งจากไจโรเซ็นเซอร์ (MPU6050) ตรวจจับการล้มของผู้สูงอายุ และส่งการแจ้งเตือนแบบทันทีผ่านเครือข่าย Wi-Fi ไปยังแอปพลิเคชัน LINE

ฮาร์ดแวร์

ESP32, MPU-6050 Gyro Sensor

การเชื่อมต่อ

Wi-Fi, LINE Notify API
