Programming Skill

การเขียนโปรแกรมภาษา Python

ภาษาแรกแห่งการเริ่มต้นเขียนโค้ด สู่การวิเคราะห์ข้อมูลเบื้องต้นและ Mini-projects

จุดเริ่มต้นการเขียนโปรแกรมและการวิเคราะห์ข้อมูล

ภาษา Python เป็นภาษาแรกที่ผมได้เริ่มศึกษาตั้งแต่ระดับประถมศึกษา ด้วยความเข้าใจง่ายและมีความยืดหยุ่นสูง ผมได้ใช้ Python ในการสร้าง Mini-projects เช่น เกมทายตัวเลข และเกมงูผ่าน Spyder IDE

ต่อมาได้นำ Python มาประยุกต์ใช้ในการจัดการและวิเคราะห์ข้อมูล (Data Analytics) เบื้องต้นผ่าน Google Colab ด้วยไลบรารียอดนิยมอย่าง Pandas และ Matplotlib ทำให้เข้าใจการสรุปผลและพล็อตกราฟแสดงข้อมูลได้อย่างเป็นรูปธรรม

เครื่องมือ

Google Colab, Spyder

ไลบรารี

Pandas, Matplotlib, NumPy
