Programming Skill

การเขียนโปรแกรมภาษา C

รากฐานการคิดเชิงโครงสร้าง สู่การแข่งขันค่าย สอวน. และการพัฒนาฮาร์ดแวร์ IoT

ได้รับการเรียนรู้ภาษา C สู่ค่าย สอวน.

ภาษา C ผมได้เรียนรู้ด้วยตนเองเมื่อได้รับประกาศว่าติดค่าย สอวน. ค่าย 1 และได้รับการอบรมเข้มข้นจากอาจารย์ในค่าย ทำให้มีพื้นฐานการเขียนโปรแกรมที่ดีขึ้น และใช้ภาษา C ในการผ่านการทดสอบจนเข้าสู่ค่าย 2 ได้สำเร็จ

ระดับ

สอวน. ค่าย 1 - 2

จุดเน้น

Pointer, Struct, Memory, Logic

ผู้ช่วยพัฒนาโครงงานเข็มขัดแจ้งเตือนการล้ม (IoT)

นำความรู้ภาษา C มาประยุกต์เขียนโปรแกรมลงในไมโครคอนโทรลเลอร์ ESP32 เพื่ออ่านค่าจากไจโรเซ็นเซอร์ (Gyroscope) และส่งสัญญาณแจ้งเตือนการหกล้มผ่าน Wi-Fi เข้าสู่ LINE Notify เพื่อดูแลผู้สูงอายุ

บทบาท

ผู้ช่วยสอนโค้ด & เชื่อมต่อวงจร

ฮาร์ดแวร์

ESP32, Gyro Sensor, Wi-Fi
